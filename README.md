# irohaboard_runtime
irohaboardの改造内容や実行環境、サンプルなどの情報をまとめます。

1. ## 変更点一覧.pdf
    irhaboardオリジナルからの変更点をまとめています。

1. ## 管理者向け機能.pdf
    管理者向けの機能を説明しています。

1. ## 受講者向け機能.pdf
    受講者向けの機能を説明しています。

1. ## IIS環境設定手順.md
    Windows11でのIIS環境下で動作させるための設定手順のサンプルをまとめています。
    
1. ## DockerDesktop環境設定手順.md
    Windows11でのDockerDesktop内で動作させるための設定ファイル、インストール手順のサンプルをまとめています。

1. ## Docker構築用ファイル類
    irohaboardをDockerで動作させるためのコンテナ構築用の設定ファイルです。  
    　Docker構築用ファイル類/docker-compose.yml, Dockerfile

1. ## サンプルコース
    閲覧ページやテストページが含まれているサンプルコースをエクスポートしたファイルです。  
    　サンプルコース/サンプルコースcsv, サンプルコース_files.zip  
    コース → インポート機能で読み込み、動作確認ができます。
